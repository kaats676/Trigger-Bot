## Русский

Автоматический триггер-бот для Minecraft (Fabric API), разработанный специально для легитной игры и минимизации шанса бана на лицензионных серверах и **Minecraft Realms**. Мод использует встроенные игровые триггеры и рассчитывает идеальные тайминги для нанесения критических ударов.

### ✨ Особенности
* **Крит-мод:** При наведении на цель персонаж автоматически подпрыгивает и наносит удар строго в фазе падения.
* **Защита от античитов (Bypass):** Задержка перед ударом рандомизирована (от 230 до 280 мс), что имитирует реакцию реального человека.
* **Удобное управление:** Включение и выключение прямо во время матча клавишей `INSERT`.
* **Умный Кулдаун:** Фиксированная задержка между атаками составляет 5 секунд.
* **Чистый код:** Никаких тяжелых ИИ-библиотек или инжектов памяти. Работает через официальные ивенты Fabric API.

### 🚀 Как установить готовый .jar
1. Перейдите во вкладку **Actions** вверху этого репозитория.
2. Кликните по самой последней успешной сборке (с зеленым чекбоксом).
3. Прокрутите страницу вниз до раздела **Artifacts** и скачайте архив `TriggerBot-Fabric-1.21.1`.
4. Распакуйте архив и перенесите файл `.jar` в папку `.minecraft/mods/`.
5. Запустите игру через версию **Fabric 1.21.1**.

## English

An advanced, bypass-focused TriggerBot modification for Minecraft (Fabric API 1.21.1). Designed to provide legitimate-looking gameplay with automatic critical hits, making it much safer for **Minecraft Realms** and licensed servers.

### ✨ Features
* **Auto-Critical Hits:** Automatically jumps when targeting an enemy player and hits precisely during the falling phase.
* **Anti-Cheat Bypass:** Features dynamic randomized delays (230ms - 280ms) to successfully mimic human reflex behaviors.
* **In-Game Toggle:** Activate or deactivate the script instantly by pressing the `INSERT` key.
* **Smart Cooldown:** Implements a strict 5-second cooldown cycle between strikes.
* **Lightweight:** No external AI libraries or memory injection. Pure vanilla Fabric event handlers.

### 🚀 How to Download the compiled .jar
1. Navigate to the **Actions** tab at the top of this GitHub repository.
2. Select the latest successful workflow run (indicated by a green checkmark).
3. Scroll down to the **Artifacts** section and download `TriggerBot-Fabric-1.21.1`.
4. Unzip the file and drop the `.jar` mod into your `.minecraft/mods/` directory.
5. Launch Minecraft using **Fabric 1.21.1**.
